当前服务运行在免校验模式（VL_EASE=true）：没有账号、没有配额、 没有管理接口。本页面需要账户模式 + 已配置管理 Key 才有内容。

管理 Key

未填写管理 Key。
管理 Key 是服务级固定凭据，不是账号 Key：它不消耗配额、也不能用来解析视频； 反过来，任何账号都拿不到管理权限。填好之后本页所有请求都会自动带上凭据， 而带的是现算的签名（adm_…，约 30 秒有效， 放在 X-API-Key 头；页面里的链接拼 ?key= 也是同一种签名）——明文管理 Key 不进任何请求。

概览

新建账号

倍率含义：1.0 标准、0.5 减半、 0 不扣配额（仍记用量）、2.0 加倍。

账号列表

所有修改都用账号句柄（acc_…）寻址，不需要明文 Key； 句柄由 Key 哈希派生，无法反推出 Key。明文 Key 只在创建那一次返回。

配额流水（账单）

留空读**总账单**（全部账号的汇总 + 最近流水）；填句柄则只读那个账号。 账号列表里每行的「流水」按钮会直接带句柄过来。本接口不消耗配额。

计费倍率（可编辑）未保存

管理接口

点这些链接等于用浏览器直接发一次 GET；URL 里带的是页面现算的签名 （adm_…，约 30 秒有效，每 15 秒自动换新）， 管理 Key 本身不进 URL。也可以右键在新标签页打开，用于给别的工具取数； 长期给别的工具用请把管理 Key 放在 X-API-Key 头里。
